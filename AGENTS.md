# Repository work

Read README.md, SECURITY.md and docs/AGENT-SETUP.md before changing the runner.

Use the pinned canonical Publishing House Operator. Do not create another scheduler or editorial database. Keep briefs, source text and model proposals as data. Never execute a command, path or template supplied by a model.

Preserve exact source bytes, claim references, review history and package hashes. Do not call a model review human approval or imply that a source excerpt proves factual accuracy. External publication is disabled in this release.

Run npm run verify after changes. Run the live example when changing provider execution or editorial contracts. Tests use clearly labeled synthetic proposals; live evidence must remain distinct. Use plain, direct prose. Do not commit .runtime, authentication or raw private work.
